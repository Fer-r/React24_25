# Proyecto de Pokemon con uso de React Router V7

Se pretende realizar un proyecto que utilice las siguientes tecnologias

    -React Router Dom en su version 7
    -Contextos globales
    -Libreria Sonner para notificaciones
    -Estilado con Tailwind CSS

El Scaffolding que se va a utilizar es el siguiente

```text
📂 src/
│
├── 📁 components/
│   └── 🧩 Navbar.jsx
│
├── 📁 context/
│   └── 🌐 PokemonContext.jsx
│
├── 📁 layout/
│   └── 🏗️ RootLayout.jsx
│
├── 📁 pages/
│   ├── 🏠 Home.jsx
│   ├── 🔍 Search.jsx
│   ├── 📄 PokemonDetail.jsx
│   └── ⭐ Favorites.jsx
│
├── 📁 routes/
│   ├── 🛤️ Routes.jsx
│   └── 🗺️ paths.js
│
├── ⚙️ App.jsx
└── 🚀 main.jsx



```
